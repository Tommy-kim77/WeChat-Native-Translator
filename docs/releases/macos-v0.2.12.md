# macOS v0.2.12

- 한국어·중국어·영어 입력이 보내는 메시지 번역 언어와 같으면 Enter 한 번으로 원문을 전송합니다. 번역 API 호출과 자동 미리보기를 건너뜁니다.
- `OK`, `Hi`, `Invoice` 같은 짧은 영어가 다른 언어로 잘못 감지되어 Enter를 여러 번 눌러야 하던 문제를 수정했습니다.
- 한국어·중국어 문장 속 제품명과 웹 주소를 보존합니다. 다른 언어는 기존대로 번역 미리보기 후 전송하며, 수동으로 수정한 미리보기도 유지합니다.

검증: 공통 언어 사례 58개(즉시 전송 42개, 번역 대상 16개), 원문 그대로 한 번에 전송, 수동 미리보기 편집, 인증 만료·재연결, 실제 ChatView 스크롤 검사가 통과했습니다. 가상 계정과 응답으로 실행했으며 실제 계정에는 메시지를 보내지 않았습니다.
