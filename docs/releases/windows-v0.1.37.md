# Windows v0.1.37

- 한국어·중국어·영어 입력이 전송 언어와 같으면 Enter 한 번으로 원문을 바로 전송합니다. 이 경우 DeepL 키와 번역 API가 필요하지 않습니다.
- 짧은 영어 `OK`, `Hi`, `Invoice`, 제품명이 포함된 한·중 문장, 웹 주소를 처리합니다.
- 다른 언어는 번역 미리보기 후 전송합니다. 번역 아이콘으로 만든 수동 미리보기의 편집과 전송 실패 시 초안 보존도 유지합니다.

Windows 10/11 x64용이며 통신 엔진은 EXE에 포함되어 있습니다. QR 로그인은 휴대폰 WeChat에서 승인하세요. 다른 언어로 번역할 때는 본인의 DeepL API 키가 필요합니다.
