# macOS v0.2.11

- 전송 버튼과 Enter 모두 자동 번역 설정에 따라 미리보기 후 전송합니다.
- 입력 언어가 전송 언어와 같거나 웹 주소만 있으면 한 번에 원문을 전송합니다.
- 계정 인증 만료와 HTTP 401 응답 시 초안을 유지하고 QR 로그인 화면을 표시합니다. 일시적인 서버 오류는 인증 만료로 처리하지 않습니다.
- 이전 대화를 읽을 때 새 메시지와 번역문 갱신으로 스크롤이 하단으로 이동하지 않습니다. 하단을 보고 있다면 번역문과 입력창 크기 변경을 따라갑니다.

검증: `bash Tests/run-macos.sh`에서 가상 URLProtocol 응답으로 전송·번역·재연결을 검증하고, 실제 ChatView를 별도 창에 띄워 스크롤을 확인했습니다. 15개 검증이 통과했습니다. 실제 계정에 메시지를 보내지 않았습니다.
