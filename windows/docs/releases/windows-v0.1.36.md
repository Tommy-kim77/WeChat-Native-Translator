# Windows v0.1.36

- QR 승인 이후 계정 또는 대화 목록 확인이 실패하면 QR 로그인을 다시 시도할 수 있습니다. 원문과 수정한 번역 미리보기는 보관합니다.
- 이전 대화를 읽는 동안 새 메시지, 번역문, 아바타 갱신으로 화면이 하단으로 이동하지 않습니다. 다시 그려도 보이던 메시지의 화면 위치를 보존합니다.
- 맨 아래로 돌아오면 새 메시지와 번역문 확장, 창 크기 변경을 따라갑니다.
- v0.1.35의 이전 메시지 페이지 조회와 전송 재시도 수정은 유지했습니다.

검증: Windows 10 22H2, .NET Framework 컴파일러로 EXE 빌드. `Tests/Regression.cs`를 제품 소스와 함께 컴파일하여 가상 메시지 기반 UI 검증 10개를 통과했습니다. `--verify-package`로 분리된 임시 프로필에서 내장 엔진 시작과 로컬 API 인증을 확인했습니다. 실제 계정에 로그인하거나 메시지를 전송하지 않았습니다.
